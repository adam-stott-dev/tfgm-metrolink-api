title: Introduction
description: Scheduled Manchester Metrolink tram times over a simple REST API.
---

The Metrolink Timetable API gives you stops, routes and upcoming departures for the
Manchester Metrolink tram network as JSON.

It is built from the official Greater Manchester timetable (GTFS), which is imported
every night. It does not call the TfGM live departures API, so it keeps working
without a TfGM key.

<Callout type="warn" title="Scheduled times only">
  Departures are the times in the published timetable. They don't include live delays,
  cancellations or disruption, and every response says `"realtime": false`.
</Callout>

## Base URL

All endpoints live under `/api/v1` on this site, for example:

```
GET /api/v1/stops/piccadilly/departures
```
